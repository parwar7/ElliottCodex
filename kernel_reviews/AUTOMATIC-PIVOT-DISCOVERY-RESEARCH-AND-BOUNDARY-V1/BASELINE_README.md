# AUTOMATIC-PIVOT-DISCOVERY-RESEARCH-AND-BOUNDARY-V1

Status: `APPROVED_CANDIDATE`

Gate: `PURE_GEOMETRIC_PIVOT_DISCOVERY_SAFE`

This logical Runtime baseline records a narrow caller-configured windowed-local-extrema implementation. It is `PROJECT_DATA_ANALYSIS_INFRASTRUCTURE`, not executable Elliott methodology.

The binding boundary is:

`GEOMETRIC_PIVOT != ELLIOTT_WAVE_ENDPOINT`

`AUTOMATIC_SWING != ELLIOTT_WAVE`

Every emitted observation has `elliott_endpoint_authority = false`. The output carries no wave label, family, degree, pattern, structural validity, forecast, ranking, indicator, certification, or trading authority. It cannot automatically enter the existing explicit-pivot candidate contracts.

The selected V1 method compares each bar's high and low with an exact bounded window. The caller must explicitly supply positive left and right window sizes, `FIRST` or `LAST` equal-extreme handling, and whether incomplete trailing windows are emitted as `DEVELOPING`. A pivot is `CONFIRMED_BY_GEOMETRY` only after its full right window exists. Confirmed history is stable under later appends because later data lies outside that bounded comparison window; developing observations may disappear or change.

If one bar is simultaneously the selected high and selected low of its window, V1 excludes it and records a diagnostic. V1 does not enforce high/low alternation, replace endpoints, prune pivots, infer nested hierarchy, or map timeframe or discovery scale to Elliott degree.

Protected sources do not define a mechanical pivot extractor, a universal reversal percentage, ATR multiple, bar window, prominence threshold, or minimum move. Those values therefore are not methodology. The one implemented algorithm avoids a hardcoded universal setting by requiring caller configuration.

The live NVDA experiment used Yahoo-normalized observations and a disclosed `2/2`, `LAST`, include-developing configuration on monthly, weekly, and daily inputs. Its outputs are geometry observations only and must not be read as an Elliott count.

All 707 tests passed. Protected Brain and Sources remained unchanged. Executable methodology remained 10; structural-invalidity producers remained 7; validated-family producers and issuances remained zero. P005, P006, the terminal/base-case finding, and legacy `analyze` remained unchanged.
