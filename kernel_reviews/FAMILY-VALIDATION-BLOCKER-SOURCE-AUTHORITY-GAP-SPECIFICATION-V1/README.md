# Family-validation blocker source-authority gap specification

This package converts the accepted family-validation blockers into one actionable source-authority requirement. It is review/governance evidence only, not methodology, an implementation baseline, a family producer, or certificate authority.

The smallest useful dependency cut is `BASE_CASE_UNRESOLVED`. Resolving completion alone could enable a completion contract but would not break family recursion. Position, endpoint, P005, and P006 authority each immediately encounters another unresolved dependency. By contrast, a protected proposition defining one exact, completed, family-specific terminal primitive can directly authorize the first genuine producer while leaving all unrelated gaps intact.

No existing approved Brain statement, protected transcript, approved review, or locally available Frost/Prechter artifact supplies that proposition. The selected gap therefore requires new approved source authority. The specification does not supply the answer: it states exactly what a future source must establish, what scope and exceptions it must cover, which machine decisions must become explicit, and which adjacent statements are insufficient.

The one required user action is `PROVIDE_APPROVED_BOOK_SOURCE`: provide a locally available, explicitly authorized Frost/Prechter *Elliott Wave Principle* artifact with stable edition/title metadata for hash and source-manifest review. The next review must search that artifact only for the selected terminal/base question and its primitive-local completion boundary.

Until that authority is supplied and approved, `METHODOLOGY_IMPLEMENTATION_PAUSED_PENDING_SOURCE_AUTHORITY`. P005 and P006 remain frozen, the protected roots remain unchanged, and the validated-family registry remains sealed with zero producers and issuances.
