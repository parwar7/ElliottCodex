# P004-V1 Methodology Logical Baseline

P004-V1 is the first executable methodology baseline. It contains exactly one source-locked Elliott rule: P004, the normal-impulse Wave 2 origin rule.

Passing P004 is not whole-candidate validation. It establishes only that this one hard-validation rule was not violated for the explicitly supplied inputs and scope.

PHASE1-FOUNDATION-V1 remains the foundation baseline. P004-V1 records the explicit Phase 1 delta without altering that foundation baseline.

Future methodology behaviors require separate source mapping, implementation, audit, and baseline approval. Any later change to P004 must be reported explicitly as a P004-V1 delta.

This is a development logical baseline. It does not claim physical immutability, ACL protection, signing, or process isolation.
