# HUMAN-ASSISTED-MULTI-DEGREE-CANDIDATE-COMPOSITION-V1

This additive logical baseline records project analysis infrastructure for
caller-supplied degree hypotheses over one exact live recursive candidate tree.
It adds no Elliott methodology behavior.

`CandidateDegreeDeclaration` retains one exact tree subject, the existing
degree representation and `DegreeStatus`, and caller provenance. A declaration
is not degree proof, confirmation, validity, or chart-derived authority.
Declarations remain in caller order; a separate subject inventory follows
recursive preorder. Zero or one declaration is allowed per exact tree subject.
Partial coverage is allowed and is reported only as
`NO_DEGREE_DECLARATION_SUPPLIED` infrastructure diagnostics.

For each recursive node with at least two direct children, a peer evaluation is
created only when every direct child has an explicit declaration. It constructs
the existing exact `DegreePeerConsistencyInput` and routes it through the
established explicit execution boundary. For each exact direct parent-child edge
whose endpoints both have declarations, the same boundary executes an existing
exact `ParentChildDegreeInput`. No peer group crosses parent boundaries and no
grandparent-to-grandchild shortcut is created.

Every evaluation retains the exact input, genuine existing result, behavior ID,
subjects, execution result, and declaration provenance. Existing violations are
retained without synthesizing a certificate or altering no-rescue behavior.
Satisfied degree relations create no family, pattern, completion, or broader
candidate validity.

An optional exact live `MultiTimeframeObservationTransportResult` may be
retained only when it belongs to the same recursive result. It is never consumed
to form a degree input. `TIMEFRAME_IS_NOT_DEGREE`: no sampling resolution,
duration, price movement, or observation availability implies degree, and
degree never implies timeframe.

The layer performs no P023 rerun, family validation, wave labeling, indicators,
ranking, trading, fetching, resampling, provider integration, or certificate
issuance.
