# AUTOMATIC-CANDIDATE-GENERATION-RESEARCH-AND-BOUNDARY-V1

Status: `APPROVED_CANDIDATE`

Gate: `NEUTRAL_AUTOMATIC_CANDIDATE_ENUMERATION_SAFE`

This logical Runtime baseline records bounded, deterministic enumeration of neutral candidate hypotheses. It adds no executable Elliott methodology.

The binding boundaries are:

`CANDIDATE HYPOTHESIS != VALID ELLIOTT COUNT`

`GEOMETRIC PIVOT != ELLIOTT WAVE ENDPOINT`

`ENUMERATION != CONFIRMATION`

V1 exposes only `THREE_SEGMENT_HYPOTHESIS` and `FIVE_SEGMENT_HYPOTHESIS`. These names count price segments and carry no A-B-C, 1-2-3-4-5, W-X-Y, family, pattern, degree, validity, rank, or forecast meaning. Candidate slot labels are deliberately omitted.

The caller supplies every operational bound: pivot consideration count, maximum pivot span, maximum skipped pivots, maximum candidate count, allowed neutral shapes, and earliest/latest consideration window. Enumeration preserves exact chronological pivot identities and deterministic order. It does not enforce HIGH/LOW alternation or select important pivots.

Eligible candidate count is calculated before materialization. If it exceeds the caller cap, generation fails before candidate enumeration and returns no partial result. Only locally bounded combinations are visited. Combinations outside span and skip bounds are counted mathematically rather than traversed.

Existing methodology runs only when the caller supplies an exact `BoundedManualChartAnalysisRequest` for an exact generated candidate ID and subject. The Runtime delegates that object unchanged through `MethodologyKernel.analyze_bounded_manual_chart` and retains the exact result. It neither constructs methodology facts nor issues certificates. Without an exact delegation, each hypothesis remains `UNRESOLVED`.

The NVDA experiment considered only the latest eight geometric pivots per timeframe. Monthly, weekly, and daily each generated 20 hypotheses; all remained unresolved because no methodology inputs were fabricated. The experiment is infrastructure output, not an Elliott analysis or forecast.

All 735 tests passed. Brain and Sources remained unchanged. Executable methodology remained 10, structural-invalidity producers 7, and validated-family producers/issuances zero.
