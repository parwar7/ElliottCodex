# Current-position boundary — not adopted

## Observed evidence

Five linked contexts reach the latest timestamp of their observation dataset:
H0428 (single-zigzag hypothesis), H0429 (flat hypothesis), H0430 (triangle
hypothesis), H0434 and H0435 (Normal Impulse partial hypotheses).
Every final pivot is DEVELOPING. The two Normal Impulse contexts have P004
satisfied and P005 unresolved because a required endpoint is developing.

This is evidence of timestamp membership in the final proposed component,
not evidence that the market is currently in a confirmed or active Elliott wave.
Generic families supply neutral child slots, not an ABC/current-position API.
Normal Impulse roles supply exact proposed endpoint pairs, not an active-wave
or developing-position contract. An endpoint price field is not the complete
latest OHLC observation or an orthodox endpoint.

No positive-family certificate is required merely to describe a hypothesis,
but neither family proof nor timestamp coincidence can be substituted for the
missing active-component semantics. P004/P005 outcomes alone do not establish it.

## Minimal next contract proposal — NOT APPLIED

Proposed target: a separate reviewed Runtime reporting contract, tentatively
SNAPSHOT-COMPONENT-MEMBERSHIP-BOUNDARY-V1. No protected file or Kernel change is
proposed by this stage. This is a design-only next step, not an implemented API.

Input: exact live family/Normal Impulse hypothesis, its original branch and
requirement identities, exact mapped roles, exact observation snapshot and
the latest observed bar in that snapshot.

Output: factual membership record identifying whether the bar timestamp is
before, within, at the end of, or after a supplied proposed component interval;
retain all OHLC fields without choosing close/high/low as current-wave proof;
retain developing metadata, P004 rejection, P005 unresolved dependencies and
trailing observations. No next-wave inference or completion authority.

An explicit CURRENT_POSITION_UNRESOLVED state remains mandatory unless a later
review establishes when such factual membership may legitimately be described
as a conditional active-wave position. That transition requires exact approved
source support or an explicitly approved project convention, not an invented
tolerance, a final-pivot rule or an arbitrary finite base case.

The current artifacts already expose the factual operands needed to review
this boundary. They do not apply the proposed transition or assert an active
component. No protected amendment, new methodology behavior, or implementation
of this proposed next contract is included.
