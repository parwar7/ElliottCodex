# Narrow search/report extension

Only two new tools and one new test module are added. No Runtime contract, Kernel, shared evidence type, source file, or historical baseline is changed. Existing exact public factories own all issued subjects, bindings, candidates, competing sets, family evaluate-as results, P004/P005 outcomes and observational links.

`select_sequences` classifies every consecutive original 4/6-point window before evaluations. Old coordinate sequences are excluded by snapshot hash, resolution, timestamps, fields and exact represented price. Equal-count-bin midpoint selection covers interior alternatives without outcome feedback. Distinct new contexts with repeated coordinates remain distinct and are counted separately from unique sequences. Selection is not Elliott significance or ranking.

`corrective` supplies exact original four-point scopes to the existing candidate, competing-set and family bridge factories. SINGLE_ZIGZAG/FLAT cardinalities execute; their existing CURRENT_SUPPLIED_SCOPE_REVIEWED state is preserved, not renamed family validity. Internal family proof stays unresolved even when that cardinality-only result has no unresolved inputs in its own narrow scope. No new family geometry or subtype checks execute. The ending-diagonal bridge inside the existing NI transport is not counted as an analytical diagonal classification.

Every new Normal Impulse context uses a fresh subject/binding. Geometry uses the unchanged exact snapshot/config cache. Matching prior windows reuse the prior deterministic discovery recipe and original observation objects; prior serialized discoveries cannot restore live issuance authority. No authority-bearing result is cached across contexts. M1/M2 alone are reconstructed from their exact saved selections and checked against prior IDs, endpoints and outcomes.

Monthly role 5 routes to new Daily NI scopes; new Daily roles route to overlapping-calendar intraday NI scopes. This is only finite routing. `link_observations` decides exact interval support, missing correspondence and P004 exclusion. All alternative occurrences/pairings are retained within predeclared caps. No result or issued object is filtered/rebound to disguise a different request.

Existing aggregate-parent interval support is Monthly/Daily only. Therefore no 4H/1H-to-15m edge is invented; these intermediate local results remain independent unless linked directly from a supported Daily role. The existing typed observational link accepts exact NI evaluations only. Corrective-family results are not coerced into it. These are current reuse limitations, not grounds to broaden this stage with another contract.

Public guards reject nested/foreign binding or snapshot substitution. Renderer exports are informational and independently raw-reconciled, never deserialized certificates. P004 rejection excludes the exact NI candidate and any path using it; it does not validate a sibling or reject the entire region. P005 sufficiency never rescues P004. The unlabelled captured tail is kept separate; no active-wave, completion or degree authority follows from the last label.

Inventories remain 11 / 7 / 0 / 0. No new source behavior, certification, ranking, indicator interpretation, forecast, trading or network retrieval is implemented.
