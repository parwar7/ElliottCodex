# SINGLE-CANDIDATE-METHODOLOGY-ORCHESTRATION-V1

This additive logical baseline records `PROJECT_ANALYSIS_INFRASTRUCTURE`. Its execution-summary precedence and presence inventory are `PROJECT_OPERATIONAL_POLICY`, not Elliott methodology.

`MethodologyKernel.analyze_candidate` accepts only one exact live `SingleCandidateAnalysisRequest` containing one exact live `CandidateAnalysisEnvelope`. The legacy `MethodologyKernel.analyze(AnalysisRequest)` boundary remains unchanged and returns `NOT_IMPLEMENTED`; arbitrary `AnalysisRequest.options` never carries candidate authority.

The orchestration boundary revalidates and retains the caller-supplied envelope, subject, evaluation attachments, observations, child binding, and bounded operational resolution. It does not invoke methodology validators, discover candidates, infer missing inputs, issue certificates, or convert transport into proof. Its deterministic ten-record inventory marks each reviewed behavior only as `SUPPLIED_AND_VERIFIED` or `NOT_SUPPLIED` and preserves the exact supplied evaluation identities and order.

The result summary vocabulary is `STRUCTURALLY_INVALID`, `UNRESOLVED`, and `SUPPLIED_EVALUATIONS_REVIEWED`. Genuine retained `CertifiedStructuralInvalidity` takes precedence over unresolved state. Without such a certificate, an unresolved bounded resolution, an unresolved supplied visibility result, an uncertified fatal-looking structural result, or zero supplied evaluations yields `UNRESOLVED`. Zero evaluations records `NO_METHODOLOGY_EVALUATIONS_SUPPLIED`. The reviewed state means only that supplied attachments revalidated and no current certified invalidity or unresolved blocker was found; it establishes no validity, completeness, family, rank, correctness, or required-behavior coverage.

Exact live identity, exact types, recursive mutation checks inherited from the candidate envelope, sealed public types, and rejected pickle restoration preserve the existing same-process authority boundary. The result retains existing certificate identity and never creates structural invalidity or fatality. Observations remain transport-only.

No Elliott behavior, protected principle ID, structural-invalidity producer, validated-family producer, family issuance, candidate discovery, pivot logic, wave labeling, degree inference, timeframe mapping, evidence scoring, scenario ranking, provider, TradingView, alert, network, or execution behavior was added.

This is a development logical baseline. It does not claim physical immutability, hostile same-process isolation, cryptographic authenticity, or durable cross-process authority.
